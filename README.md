# Vue Project 2026 (Fullstack)

Учебный fullstack-проект. 
**Архитектура:** Гибридная. Код (фронтенд и бэкенд) запускается локально для удобства разработки, а база данных (MySQL) находится на удаленном сервере (VPS) и подключается через защищенный SSH-туннель.

## Первоначальная настройка (После клонирования)

Тяжелые папки и секретные ключи не хранятся в Git, после скачивания проекта нужно сделать два шага:

**1. Установка зависимостей:**
```bash
cd backend && npm install
cd ../frontend && npm install
```

**2. Создать файл .env:**
В папке `backend` создайте файл `.env` и добавьте в него следующие строки (подставьте свои пароли):
```text
PORT=3000
DB_HOST=127.0.0.1
DB_PORT=3366
DB_USER=admin
DB_PASSWORD=ваш_пароль_от_базы
DB_NAME=vue_project_2026
JWT_SECRET=my_super_secret_key_2026
```

## Запуск проекта

Для работы проекта должны быть параллельно открыты **3 вкладки терминала**:

### Терминал 1: Поднятие туннеля к БД
Пробрасываем защищенный канал от локального порта 3366 к порту базы 3307 на сервере.
```bash
ssh -L 3366:127.0.0.1:3307 root@176.12.68.14
```
*(После ввода пароля от сервера появится строка `root@ваш_логин:~#` — туннель работает, вкладку можно свернуть.)*

### Терминал 2: Запуск Backend (Node.js)
```bash
cd backend
node index.js
```
*(Успешный статус: "УСПЕХ: База данных на сервере ответила и подключилась!")*

### Терминал 3: Запуск Frontend (Vue.js)
```bash
cd frontend
npm run serve
```
